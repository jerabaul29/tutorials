# Tutorials

My personal (small-scale) tutorials, notes on how to do stuff, etc. The goal is to document things that took me a bit of time to figure out :) .

Nothing here comes with any warranty - if you find a mistake, have a comment, want to suggest an improvement, open a pull request!

In general, each tutorial folder will contain a .ipynb notebook that should be displayable directly in Github, and files on the side of it to provide some implementations, extra documentation, etc.
